Installation Guide

Set up MeetingTool on a new machine in about 10 minutes. You need Python, ffmpeg, and a git client — the installer handles everything else.

Install ffmpeg

ffmpeg must be installed and available on your system PATH before running the MeetingTool installer. The installer will check for it and guide you if it's missing.

The easiest method is winget (built into Windows 11):

winget install Gyan.FFmpeg

Or install manually:

  1. Download the Release Full build from ffmpeg.org/download.html → Windows → gyan.dev
  2. Extract to C:\ffmpeg\
  3. Add C:\ffmpeg\bin to your system PATH:
    Win+X → System → Advanced system settings → Environment Variables → System Variables → Path → Edit → New
  4. Close and reopen your terminal, then verify: ffmpeg -version
brew install ffmpeg

Requires Homebrew. If you don't have it: brew.sh

# Ubuntu / Debian
sudo apt install ffmpeg

# Fedora
sudo dnf install ffmpeg
Verify the install

Run ffmpeg -version in a new terminal window. You should see version info. If the command is not found, close and reopen your terminal — PATH changes require a fresh session.

Install MeetingTool

1
Clone the repository

Choose a permanent location for the MeetingTool program files — this is not where your meeting recordings or reports will go (the installer will ask you that separately).

git clone https://github.com/diegomondrik/meetingtool.git
cd meetingtool
New to git clone?

This command downloads MeetingTool into a new subfolder called meetingtool inside whichever folder your terminal is currently in. Navigate to your preferred location first, e.g. cd C:\Tools on Windows or cd ~/Applications on Mac.

2
Run the installer
python mip.py setup

The installer will walk you through these steps automatically:

  • Verify Python version and ffmpeg
  • Install required Python packages
  • Choose where to store projects and meeting recordings
  • Choose your AI tool (Claude, ChatGPT, or Gemini)
  • Set default report language (English or Spanish)
  • Enter API keys (optional — stored securely in the system keychain)
  • Create the folder structure
  • Generate a Windows launcher (MeetingTool.bat)
Windows: multiple Python versions

If you have more than one Python installed, the installer will detect this and print a warning. It will create the launcher using the exact Python version you ran setup with, so double-clicking MeetingTool.bat always uses the right one.

3
Verify the install
python mip.py --help

You should see the list of available commands. If setup completed without errors, MeetingTool is ready to use.

Create Your First Project

MeetingTool organizes work by client and project. Run this command to set up your first one:

python mip.py project new

You'll be asked for the client name, project name, meeting language, and which AI tool to use. At the end, MeetingTool prints the exact instructions to configure your Claude Project (or ChatGPT/Gemini equivalent) — follow those before analyzing your first meeting.

Troubleshooting

ffmpeg not found after installing
PATH changes require a new terminal session. Close your terminal completely, reopen it, and run ffmpeg -version again. On Windows, also make sure you added the bin subfolder (e.g. C:\ffmpeg\bin), not just C:\ffmpeg.
python not found on Windows
During Python installation, the "Add Python to PATH" checkbox must be checked. If you missed it, uninstall Python and reinstall with that option enabled. Alternatively, use py mip.py setup instead of python mip.py setup.
Package installation fails during setup
Try running the installer again — it retries failed packages. If a specific package keeps failing, install it manually: pip install <package-name>. Common culprits on ARM64 machines: scikit-image and pillow may need Visual C++ Build Tools.
Keyring error when saving API keys
On some minimal Linux installs, the keyring backend is not configured. Install a backend: pip install secretstorage keyrings.alt, then run python mip.py setup again.
Running setup again to change settings
python mip.py setup is safe to re-run. It will detect the existing install and ask before overwriting. Your projects and recordings are never affected — only the global config is updated.
