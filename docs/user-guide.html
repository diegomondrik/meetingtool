MeetingTool v3.0

User Guide

MeetingTool processes Teams recordings and generates structured executive reports. Choose the workflow that matches how you use AI — fully automated, via Claude Desktop, or through any LLM browser.

Workflows

Three workflows are available. Pick based on the tools you have access to:

Workflow A
Automated Pipeline
Gemini extracts frames, Claude writes the report. Fully hands-off. Requires API keys.
Workflow B
Cowork
Claude Desktop reads frames and transcript directly. No API keys needed.
Workflow C
Web
Upload checklist for any LLM browser — Claude, ChatGPT, Gemini. Most flexible.
Don't have API keys?

Workflows B and C work entirely without API keys. Workflow A is the only one that requires them.

Projects

MeetingTool organizes meetings by client and project. Create a project once per engagement — then run meeting analysis commands from within it.

# Create a new project
python mip.py project new

# List all projects
python mip.py project list

When you create a project, MeetingTool will ask for:

  • Client name — used to organize the folder structure
  • Project name — the specific engagement or workstream
  • Default report language — English or Spanish (can be overridden per meeting)
  • LLM provider — Claude, ChatGPT, or Gemini

At the end, MeetingTool prints the Claude Project Instructions (or equivalent) that you paste into your AI tool. Do this before analyzing your first meeting.

python mip.py export --path "<meeting_folder>"
Language detection

If the meeting transcript language differs from the project default, MeetingTool prompts you to choose: project default, meeting language, or both (two separate report files).

Workflow A — Automated Pipeline

Fully hands-off. Gemini extracts visible content from screen captures; Claude writes the full report. Requires an Anthropic API key and a Gemini API key.

1
Prepare the meeting folder

Place the recording and transcript in the same folder, named with the meeting date:

MeetingName_YYYYMMDD.mp4
MeetingName_YYYYMMDD.docx
2
Run the automated pipeline
python mip.py run --path "<meeting_folder>" --auto

MeetingTool will extract frames (720p, SSIM-deduplicated), send them to Gemini for visual analysis, then call Claude to generate the report. The output is report_YYYYMMDD.md in the meeting folder.

3
Review and export
# When the report is approved
python mip.py export --path "<meeting_folder>"
Privacy

In automated mode, frames are sent to Google Gemini and the full transcript is sent to Anthropic Claude. Review their data policies before processing confidential client content.

Gemini quota and fallback

The free Gemini tier allows 1,500 requests/day. If the primary key hits quota, a backup key activates automatically (configure it during setup). If Gemini is completely unavailable, MeetingTool activates an OCR fallback — Claude generates the report from the transcript only. Report quality is lower without visual evidence, but the pipeline never blocks.

Workflow B — Cowork (Claude Desktop)

For users running Claude Desktop with the Cowork integration. MeetingTool extracts up to 150 frames intelligently and makes them available for Claude to read directly — no API keys required.

1
Prepare the meeting folder
MeetingName_YYYYMMDD.mp4
MeetingName_YYYYMMDD.docx
2
Run from Cowork
mip run --path "<meeting_folder>"

MeetingTool extracts frames, reads the transcript, and prepares the context. Claude Desktop generates report_YYYYMMDD.md through the Cowork interface.

3
Review in Cowork, then export

Iterate on the report directly in the Cowork chat. When satisfied:

mip export --path "<meeting_folder>"

Workflow C — Web (any LLM browser)

For users running Claude web, ChatGPT, or Gemini without desktop access. MeetingTool selects the best frames and prints a step-by-step upload checklist.

Short meetings (under 45 min)

1
Generate the upload checklist
python mip.py run --path "<meeting_folder>" --web

MeetingTool selects the 20 best frames and prints an upload checklist in the terminal.

2
Upload to your LLM browser

Follow the checklist: upload the transcript file and the selected frames to a new chat. Paste the prompt pack printed in the terminal.

3
Save and export

Copy the generated report and save it as report_YYYYMMDD.md in the meeting folder. Then export when ready:

python mip.py export --path "<meeting_folder>"

Long meetings (45+ min) — two-pass mode

For meetings over 45 minutes, use two-pass mode. It splits the meeting into two halves, analyzes each separately, then produces a merged final report.

python mip.py run --path "<meeting_folder>" --web --two-pass
  1. Chat 1: upload first half transcript + 20 frames → paste Chat 1 prompt pack
  2. LLM generates partial analysis + handoff JSON block
  3. Run mip handoff save --path <folder> → paste the handoff JSON when prompted
  4. Chat 2: upload handoff.json + second half transcript + 20 frames → paste Chat 2 prompt pack
  5. LLM generates the complete merged report

Meeting Types

Five types are available by default. The type determines which additional sections appear in the report.

TypeCLI keyAdditional report sections
Discovery / Pre-salesdiscoverySales signals, project fit, opportunity assessment
Kickoff / Project startkickoffProject definition, team structure, success criteria
Status / ProgressstatusProject status, delta since last meeting, blockers
Technical / AnalysistechnicalTechnical decisions, visual analysis, dependencies
Training / EnablementtrainingTraining context, comprehension, gaps & follow-up, adoption next steps

Custom meeting types can be added per project in mip.config.json inside the project folder.
